# Corpus de segmentation (lignes): ajouts postérieurs, corrections

Ce corpus contient un ensemble de pages annotées contenant des annotations marginales. Les annotations ne concernent que ces lignes: seules quelques lignes sont dont présentes par page. 

Le corpus est organisé en suivant une logiste chronologique dans la production des minutiers:
- la première phase d'écriture du minutier (écriture/complétion de la minute) est annotée dans le dossier `strate_1`. Dans ces données, **les ajouts postérieurs sont ignorés**
- la deuxième phase, qui correspond à tous les ajouts effectués postérieurement par le même ou un autre greffier et qui viennent donner une information sur l'évolution de la peine (commutation, amnistie, réduction, annulation, etc)  est annotée dans le dossier `strate_2`. Dans ces données, **seuls les ajouts sont annotés**.

La logique est celle d'entraîner la machine à distinguer entre ces strates, et de produire des modèles spécialisés sur une strate précise.
